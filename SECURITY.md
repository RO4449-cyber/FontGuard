# Security policy

FontGuard exists to protect players, so security reports are very welcome.

## Reporting a problem

If you find a way to get a malicious font (or anything else) past FontGuard, please **do not open a public
issue.** Instead, report it privately through GitHub:
**Security → Report a vulnerability** on this repository.

Please include:
- the Minecraft version and FontGuard version
- what you did and what happened
- a sample file, if you can share one safely

## Supported versions

Only the latest release gets security fixes.
